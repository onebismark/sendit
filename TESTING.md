# Real-device test checklist

Use the deployed https address, not localhost.

1. Laptop on Wi-Fi, phone on mobile data: open Workspace on the laptop, scan the QR code with the phone, tap Join room.
2. Both screens show the same three-part check phrase. If not, leave the room.
3. Send a small file from each side. The receiver must tap Accept first.
4. Send a file of about 200 MB. In Chrome or Edge on the laptop, choose where to save it; check it opens correctly.
5. Start a large transfer and turn the sender's Wi-Fi off for 10 seconds, then on. Press Retry and confirm it continues instead of starting at zero.
6. Tick "Relay only" and send a file. The device list should say "Via relay". If it fails, TURN is not set up correctly.
7. Install the app from the phone's browser menu, then share a file to Sendit from the gallery or files app.
8. Submit the contact and waitlist forms and confirm the entry arrives (database row or email).
9. Open every page directly by address (/about, /faq, /privacy ...) and refresh it.
10. Paste your address into a chat app and confirm the preview image and title appear.
