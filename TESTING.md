# Real-device test checklist

Use the deployed https address, not localhost.

1. Cloud sharing: tap Create code on one device, scan the QR code with the other, tap Allow, compare the check phrase, and send a file (the receiver taps Accept, or tick automatic accepting).
2. Drop a file on the first device before pairing. Pair the second device and confirm the file sends by itself.
3. Open the Text tab on both devices. Type on one and confirm it appears on the other as you type, then the reverse.
4. Phone on mobile data and laptop on Wi-Fi: pair them and send a file. If a direct connection fails, a message says the server relay is being used after about 7 seconds.
5. Tick "Use the server relay only", send a file, and confirm it arrives intact.
6. Send a large file in Chrome or Edge on a computer and choose where to save it. Check it opens.
7. Start a large transfer, turn the sender's Wi-Fi off for 10 seconds, then on. Press Retry and confirm it continues.
8. Same network: visit the site once on each device with internet. Then turn internet off (a phone hotspot with mobile data off works). Tap Same network on both, tap Create local invitation on one, scan it with the other, then scan the reply back. Send a file and text.
9. Same network without a camera: copy the invitation text or Save as file, send it over any app, paste it (or Open pairing file) on the other device, tap Accept pairing, and send the reply back the same way.
10. Install the app from the browser menu, then share a file to Sendit from another app.
11. Submit the contact and waitlist forms and confirm the entry arrives.
12. Open every page directly by address and refresh it.
