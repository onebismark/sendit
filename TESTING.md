# Real-device test checklist

Use the deployed https address, not localhost.

1. Two devices on the same Wi-Fi with internet: pair with the room code or QR code, compare the check phrase, send a file (the receiver taps Accept).
2. Phone on mobile data and laptop on Wi-Fi: pair them and send a file. If a direct connection fails, a message says the server relay is being used after about 10 seconds. The device list then says "Via server relay".
3. Tick "Use the server relay only", send a file, and confirm it arrives intact.
4. Send a file of about 200 MB. In Chrome or Edge on a computer, choose where to save it and check it opens.
5. Start a large transfer and turn the sender's Wi-Fi off for 10 seconds, then on. Press Retry and confirm it continues instead of starting at zero.
6. Offline: visit the site once on each device with internet. Then turn internet off (use a phone hotspot with mobile data off, or a router with no internet). Open the site from the home screen or browser, go to Offline, pair by swapping codes, and send a file.
7. Install the app from the browser menu, then share a file to Sendit from another app.
8. Submit the contact and waitlist forms and confirm the entry arrives.
9. Open every page directly by address and refresh it.
